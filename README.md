# 🎮 公会系统 · 玩法说明

> **NeoForge 1.21.1** · [⬇ 下载 Release](https://github.com/ShylynnLee/mc-guild-system/releases) · [🔧 技术文档](技术文档.md)

> **一句话**：和朋友共建公会 → 圈地盖房 → 打成就升级 → 解锁 Buff 和更大领地。

---

## 快速开始（4 步）

1. **建公会** `/guild create 公会名` → 你就是会长
2. **摆终端** 创造栏取「公会终端」→ 放在基地
3. **圈地** 站终端旁 `/guild claim 领地名` → 以终端为中心的领地归你了
4. **拉人** `/guild invite 好友ID` → 对方 `/guild accept`

**聊天菜单提示**：先按 `T` 打开聊天框，点击带 `☞` 且带下划线的文字即可执行命令。

## 🔄 核心玩法循环

```
打成就 → 公会升级 → 领地变大 + Buff 变强
   ↑                            ↓
   └──── 和朋友一起建家/打Boss/做机械 ←┘
```

## 🏰 玩法详解

### 1️⃣ 领地 —— 你的地盘
- 以**公会终端**为中心的方块区域，纵向**从虚空到天空**
- **权限隔离**：外人进你领地**不能**挖、建、开箱子、用工具
- 可以**命名**多块领地（如「主基地」「分矿」），各自独立设权限
- 会长/管理员：`/guild unclaim` 删领地、`/guild tp 领地名` 5秒传送过去

### 2️⃣ 升级 —— 靠成就，不是刷材料
| 升级 | 需要成就（任一成员完成） |
|------|----------------------|
| Lv2 | 制作工作台 |
| Lv3 | 获得铁锭 |
| Lv4 | 安山合金（Create） |
| Lv5 | 机械压力机 |
| Lv6 | 精密构件 |
| Lv7 | 蒸汽引擎 |
| Lv8 | 进入末地 |

**谁先做完算谁的** —— 队友进度共用，一起肝更快！
成就满了 → 会长 `/guild upgrade` 确认 → **只能一级一级升**，不能跳。

### 3️⃣ 升级奖励 —— Buff + 领地变大
- **领地半径**：24 起，每级 +8，**无上限**（等级越高地盘越大）
- **领地内 Buff**（只对自己公会成员生效）：

| 等级 | 挖掘 | 奔跑 | 治疗 |
|------|------|------|------|
| Lv2 | I | — | — |
| Lv4 | II | I | — |
| Lv5 | II | II | — |
| Lv8 | II | II | II |

### 4️⃣ 公会仓库 —— 共享物资
- 三个仓库：**装备** `/guild storage equipment`、**矿物** `/guild storage materials`、**方块** `/guild storage blocks`
- **容量随公会等级涨**：Lv1=9格 → Lv6+=54格（6行大箱）
- 会长可逐个成员开关权限（支持离线成员）：`/guild warehouse 好友ID on/off`
- 服务器总开关：`config/guild-warehouse.json` 的 `enabled` 字段，修改后下次打开仓库自动生效
- 打到的稀有装备、挖到的矿，全公会共用！

### 5️⃣ 保护 —— 不怕熊孩子
- 领地内**爆炸无效**（苦力怕炸不坏，会长可关）
- 死了**物品掉在墓碑**，去捡就行
- 进出领地有提示，谁进谁出一目了然

## 🕹️ 一局典型游玩

```
开局:  /guild create 众神之城
        摆终端 → /guild claim 主基地

第一天: 砍树做工作台 → ✅公会升Lv2 → Buff:挖掘I
        好友 /guild accept 加入 → 一起挖矿

中期:  装 Create → 做安山合金/压力机 → ✅升Lv4~Lv5
        领地变大 → 搭机械流水线 → 仓库共享资源
        /guild claim 分矿 圈第二块地（Lv5解锁）

后期:  蒸汽引擎 ✅Lv7 → 奔跑II+治疗II
        组队下灾变Boss / 暮色森林 → 稀有装备进仓库
        进末地 ✅Lv8 → 全Buff满级
```

## ⌨️ 常用命令速查

| 想做什么 | 命令 |
|---------|------|
| 打开管理菜单 | `/guild menu` |
| 建公会 | `/guild create <名>` |
| 圈地/删地 | `/guild claim <名>` / `/guild unclaim <名>` |
| 传送回基地 | `/guild tp <领地名>`（支持 Tab 补全本公会领地） |
| 邀请/接受 | `/guild invite <ID>` / `/guild accept` |
| 仓库 | `/guild storage equipment` / `materials` / `blocks` |
| 升级确认 | `/guild upgrade` |
| 查看状态 | `/guild info` |
